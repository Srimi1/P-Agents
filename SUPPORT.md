# Support

## Getting help

* **Docs first:** `README.md` (quick start, REPL commands, config, tools) + `config.default.toml` comments + `CONTRIBUTING.md` for the dev gate.
* **Questions / ideas:** [GitHub Discussions](https://github.com/Srimi1/P-Agents/discussions) — preferred over issues for open-ended topics.
* **Bugs / features:** Use the issue templates (Bug report / Feature request). Security-sensitive? See `SECURITY.md`.

## Response expectations

Maintained by [@Srimi1](https://github.com/Srimi1) in spare time — expect a reply within 2–3 business days.

## Versions

Only `main` / latest `0.1.x` is supported. Pin your fork to a tagged release if you need stability.
